EduTrack — Student Management System

A live, in-browser simulation of the EduTrack console application. Type menu choices like the real Python + MySQL program, watch the workflow execute step by step, and see the exact SQL each action runs.

Try the console workflow

This terminal reproduces the menu, prompts, validation and messages from src/main.py. Nothing is stored on any server — records live in this browser tab only.

edutrack — python src/main.py

What the workflow demonstrates

Each menu action runs the same logic as the real application.

  1. 1
    Add StudentCollects 12 validated fields — name, gender, DOB, class, section, roll no, email, phone, address, admission date — then runs an INSERT.
  2. 2
    Search by Roll NumberFinds one record with a SELECT ... WHERE roll_no = %s and prints the profile card.
  3. 3
    Search by Student IDPrimary-key lookup — the same profile view, keyed on the auto-increment ID.
  4. 4
    View All StudentsLists every row as a profile card.
  5. 5
    Update StudentShows current details, re-collects all fields, then runs an UPDATE.
  • 6
    Delete StudentShows the record, asks for a Y/N confirmation, then runs a DELETE.
  • 7
    ExitCloses the console gracefully; the demo restarts it.

    • Behind the scenes

    The real app (Python + mysql-connector-python) runs these prepared statements against MySQL using a repository layer:

    -- schema.sql → students table INSERT INTO students (first_name, last_name, gender, dob, `class`, section, roll_no, email, phone, address, admission_date) VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s); SELECT * FROM students WHERE roll_no = %s; SELECT * FROM students WHERE student_id = %s; SELECT * FROM students; UPDATE students SET first_name=%s, ..., admission_date=%s WHERE student_id = %s; DELETE FROM students WHERE real_student_id = %s;

    The demo stores records in localStorage so you can refresh and keep your data. Reset anytime by typing reset at the prompt. Validation rules (positive integers, email/phone patterns, gender choices, YYYY-MM-DD dates, unique roll numbers) match input_validators.py.
